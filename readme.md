### Сервис начисления бонусов
Сервис предназначен для хранения баллов. Предположительно за начисления (в т.ч. за какие конкретно действия начисляются
баллы) отвечает другой сервис.

Храним всю историю начисления и списания бонусов. Могут приходить положительные и отрицательные числа в зависимости
от типа операции. Существует только один метод обновления баланса - `store` в `BonusController`, т.к. храним историю
всех операций. Метод обновления доступен только для админов. 

Обычные пользователи могут получить историю начисления/списания бонусов и итоговый баланс.

На вход принимаются целые числа, т.к. хранить и обрабатывать лучше в них. С float могут быть проблемы и потери данных.
